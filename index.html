01

출력과 입력

계산이 끝나도 화면에 저절로 나오지 않는다. 보여줄 때만 print를 쓴다.

print

함수

괄호 안을 화면에 찍는다. 찍고 나면 남는 값은 없다.

print(값들, sep=" ", end="\n")

  • 값 사이에는 빈칸 하나가 들어간다. 숫자는 그냥 넣어도 된다.
  • "안녕" + 1은 오류다. print("안녕", 1)은 된다.
  • x = print(1)이면 1이 찍히고, x는 None이다.
b = 2
print("b =", float(b))
# b = 2.0

input

함수

키보드로 한 줄을 읽는다. 숫자처럼 보여도 글자다.

input("안내 문구")

  • Enter 앞의 글자만 돌려준다. 엔터 자체는 빠진다.
  • 계산에 쓰려면 int(input())처럼 숫자로 바꾼다. abc를 넣으면 int에서 오류가 난다.
n = int(input("Enter a number: "))
# 4를 치면 n은 정수 4

f-string

문법

문자열 앞에 f를 붙이면 중괄호 안을 계산해서 그 자리에 넣는다.

f"글자 {식} 글자"

  • 중괄호 안에는 변수뿐 아니라 비교나 계산도 된다.
  • f-string은 글자를 만들 뿐이다. 화면에 내려면 print가 따로 필요하다.
one, two, three = 1, 2, 3
print(f"one<two<three : {one < two < three}")
# one<two<three : True

#

문법

실행에서 빼는 기호는 #다. 따옴표 세 개는 주석이 아니라 글자다.

# 여기부터 줄 끝은 무시

  • #부터 그 줄 끝까지 읽지 않는다.
  • """..."""는 여러 줄 글자다. 변수에 안 담으면 그냥 버려진다. 실습 파일은 이걸로 코드를 꺼 두었다.
print(1)
# print(2) 이 줄은 실행되지 않는다

02

변수와 자료형

이름은 값을 가리킨다. = 은 같다는 뜻이 아니라 오른쪽을 이름에 넣는 기호다.

=

문법

오른쪽을 먼저 계산하고, 그 결과를 왼쪽 이름에 넣는다.

name = 식

  • 같냐고 물을 때는 ==를 쓴다.
  • number = number - 2는 예전 값을 먼저 읽고, 그 다음에 이름을 바꾼다. 없는 이름으로는 시작할 수 없다.
name = "World"
name = "Ada"
number = 9.0
number = number - 2

a = b = 값

문법

오른쪽 값 하나를 두 이름이 같이 가리키게 한다.

a = b = 2

  • 그 다음 a = 3을 해도 b는 2로 남는다. 정수는 그 자리에서 안 바뀌기 때문이다.
a = b = 2
a = 3
print(a, b)
# 3 2

언패킹

문법

오른쪽의 칸을 왼쪽 이름들에 앞에서부터 하나씩 넣는다.

a, b, c = 리스트

  • 이름 개수와 칸 개수가 다르면 오류다.
  • split으로 자른 나이는 숫자가 아니라 글자 "24"다.
words = ["Alice", "24", "Engineer"]
name, age, job = words
print(name, age)
# Alice 24

int float str bool

자료형

정수, 소수, 글자, 참/거짓. 리스트와 딕셔너리는 뒤 장에 있다.

type(값)

  • 9는 정수, 9.0은 소수다. 나눗셈 /의 결과는 소수다.
  • 비교와 in의 결과는 True 또는 False다.
print(type(9))
print(type(2 == 3))
# <class 'int'>
# <class 'bool'>

03

형 변환

변환 함수는 새 값을 만든다. 원래 변수는 그 결과를 다시 넣기 전까지 그대로다.

int()

함수

정수로 만든다. 소수는 소수점을 버린다.

int(값)

  • int(9.9)는 9다. 반올림이 아니다.
  • int("9")는 된다. int("9.0")은 안 된다. 그때는 int(float("9.0")).
print(int(9.0))
print(int("9"))
# 9
# 9

float()

함수

소수로 만든다. 정수 2는 2.0이 된다.

float(값)

  • float("9")와 float("9.5")는 둘 다 된다.
b = 2
print(float(b))
# 2.0

str()

함수

값을 글자로 만든다. 글자끼리 이어 붙일 때 필요하다.

str(값)

  • "a = " + 1은 오류다. "a = " + str(1)은 된다.
  • print는 알아서 글자로 바꾸므로, 출력만 할 때는 str이 없어도 된다.
a = 1
print("a = " + str(a))
# a = 1

list()

함수

반복되는 값을 리스트로 만든다. 괄호만 있으면 빈 리스트다.

list(값)

  • []와 list()는 둘 다 빈 리스트다.
  • 튜플을 넣으면 같은 순서의 리스트가 새로 생긴다. 원래 튜플은 안 바뀐다.
t = (1, 2, 3)
lst = list(t)
lst.append(4)
print(lst, t)
# [1, 2, 3, 4] (1, 2, 3)

tuple()

함수

리스트 등을 튜플로 만든다.

tuple(값)

  • ()와 tuple()는 빈 튜플이다.
  • 딕셔너리의 items()를 넣으면 (키, 값) 쌍의 튜플이 된다.
print(tuple([10, 20, 30]))
# (10, 20, 30)

dict()

함수

딕셔너리를 만든다. 빈 중괄호 {}도 딕셔너리다.

dict(city="Daegu")

  • {}와 dict()는 빈 딕셔너리다.
  • 쌍의 리스트를 넣으면 앞이 키, 뒤가 값이다.
print(dict(city="Daegu", country="Korea"))
rows = (("Kisub", "Pizza"), ("Sungmin", "Chicken"))
print(dict(rows)["Sungmin"])
# Chicken

04

연산자

괄호를 먼저 하고, 그다음 **, 그다음 * / // %, 그다음 + - 다. 비교는 계산이 끝난 뒤에 한다.

산술

연산자

숫자의 계산. +와 *는 글자, 리스트, 튜플에서는 이어 붙이기다.

+ - * / // % **

  • /는 나누어떨어져도 소수다. 5 / 2는 2.5, 5 // 2는 2.
  • %는 나머지, //는 몫, **는 거듭제곱이다. x ** 0.5는 제곱근.
  • 글자를 +로 이을 때는 양쪽이 모두 글자여야 한다.
n = 9.0
print(n / 2)    # 4.5
print(n % 2)    # 1.0
print(n // 2)   # 4.0
print(n ** 3)   # 729.0

+= -= *=

연산자

지금 값에 계산해서 같은 이름에 다시 넣는다.

n += 5

  • n += 5는 n = n + 5와 같다. -=는 빼고, *=는 곱한다.
  • 왼쪽은 이미 있는 이름이어야 한다.
number = 9.0
number -= 2
number += 5
print(number)
# 12.0

비교

연산자

두 값을 견주어 True 또는 False가 된다.

== != < > <= >=

  • =는 넣는 것이고 ==는 같은지 묻는 것이다.
  • 1 < 2 < 3은 1<2 와 2<3 이 둘 다 참일 때만 참이다.
print(2 == 3)
print(1 < 2 < 3)
# False
# True

in

연산자

왼쪽에 있는 것이 오른쪽에 있으면 True. 오른쪽 종류마다 기준이 다르다.

값 in 묶음

  • 글자에서는 연속된 부분인지 본다. "Py" in "Python"은 참.
  • 리스트와 튜플에서는 칸 하나가 같은지 본다.
  • 딕셔너리에서는 키만 본다. 값은 찾지 않는다.
d = {"major": "Math"}
print("major" in d)
print("Math" in d)
# True
# False

05

반복

while은 조건이 참인 동안, for는 줄을 끝까지 돌 때까지.

while

문법

조건을 보고, 참이면 본문을 한 번 한 뒤 다시 조건을 본다.

while 조건:

  • 처음부터 거짓이면 본문은 한 번도 안 돈다.
  • 본문에서 조건을 바꾸지 않으면 끝나지 않는다. 들여쓴 칸이 본문이다.
string = "A"
while len(string) < 2:
    string = "Python"
# 길이가 6이 되면 반복을 나온다

for

문법

오른쪽에서 하나씩 꺼내 왼쪽 이름에 넣고 본문을 실행한다.

for 이름 in 묶음:

  • 리스트, 글자, range, zip에 쓸 수 있다.
  • 반복이 끝나면 이름은 마지막 값을 가리킨 채로 남는다.
for i in range(1, 4):
    print(i)
# 1
# 2
# 3

range

함수

정수 줄을 만든다. 끝 숫자는 포함하지 않는다.

range(시작, 끝)

  • range(3)은 0, 1, 2다. range(1, 4)는 1, 2, 3이다.
  • 1부터 n까지 돌리려면 range(1, n + 1)이다.
  • range 자체는 리스트가 아니다. 리스트로 보려면 list(range(3)).
n = 3
print(list(range(1, n + 1)))
# [1, 2, 3]

중첩 for

문법

바깥이 한 번 움직일 때마다 안쪽이 처음부터 끝까지 돈다.

for i in ...: for j in ...:

  • print("\n", i, "단")은 먼저 줄을 바꾸고, 빈칸, 숫자, 빈칸, 단을 찍는다. 빈칸은 print가 넣는다.
n = 2
for i in range(1, n + 1):
    for j in range(1, n + 1):
        print(i, "*", j, "=", i * j)

06

인덱스와 슬라이스

글자, 리스트, 튜플이 위치를 세는 방식이 같다. 0이 첫 칸이고, 끝 번호는 빠진다.

인덱스

문법

0부터 센다. -1은 마지막 칸이다.

묶음[번호]

  • 범위를 벗어나면 오류다.
  • 리스트만 이 칸에 새 값을 넣을 수 있다. 글자와 튜플은 조회만 된다.
s = "Python"
print(s[0], s[-1])
# P n

슬라이스

문법

시작부터 끝 직전까지 잘라 새 값을 만든다. 끝 번호는 포함되지 않는다.

묶음[시작:끝:간격]

  • [:3]은 0, 1, 2다. [-2:]는 끝에서 두 개다. [::-1]은 순서를 뒤집은 새 값이다.
  • "Python"[1:-1]은 ytho다. 첫 글자와 마지막 글자가 빠진다.
  • 원래 값은 안 바뀐다.
lst = [10, 20, 30, 40, 50]
print(lst[:3])
print(lst[-2:])
print(lst[::2])
# [10, 20, 30]
# [40, 50]
# [10, 30, 50]

len

함수

칸이 몇 개인지 알려 준다.

len(값)

  • 글자는 글자 수, 리스트와 튜플은 칸 수, 딕셔너리는 키의 개수다.
  • 마지막 번호는 len(값) - 1이다. len 자체는 칸 번호가 아니다.
print(len("Python"))
print(len({"a": 1, "b": 2}))
# 6
# 2

07

문자열

글자 함수는 원본을 고치지 않는다. 바뀐 글자를 쓰려면 이름에 다시 넣어야 한다.

글자는 못 고친다

자료형

한 글자를 바꿔 넣을 수 없다. 조각을 이어 새 글자를 만든다.

뒤 + 가운데 + 앞

  • s[0] = "a"는 오류다.
  • 첫 글자와 끝 글자 교환은 대입이 아니라 다시 조립이다.
s = "Python"
result = s[-1] + s[1:-1] + s[0]
print(result)
print(s)
# nythoP
# Python

split

메서드

기준 글자로 잘라 리스트를 만든다.

s.split()

  • 괄호를 비우면 빈칸으로 자른다. 연속된 빈칸은 하나로 본다.
  • 쉼표로 자르려면 split(","). 마침표는 따로 안 떨어진다. "watched."는 그대로 한 칸이다.
print("Python is fun".split())
print("Alice,24,Engineer".split(","))
# ['Python', 'is', 'fun']
# ['Alice', '24', 'Engineer']

join

메서드

구분자 쪽에 글자들을 받아, 사이에 구분자를 끼워 하나로 만든다.

" ".join(리스트)

  • 메서드 앞이 구분자다. 합칠 대상이 아니다.
  • 글자를 넘기면 한 글자씩 자른다. "-".join("HELLO")는 H-E-L-L-O.
  • 숫자 칸이 섞이면 오류다. 먼저 str로 바꿔야 한다.
words = ["Python", "is", "fun"]
print(" ".join(words))
print("-".join("HELLO"))
# Python is fun
# H-E-L-L-O

replace

메서드

찾은 부분을 다른 글자로 바꾼 새 글자를 만든다.

s.replace(".", "")

  • 빈 글자로 바꾸면 그 부분이 지워진다.
  • 마침표와 쉼표를 둘 다 지우려면 replace를 두 번 하고, 매번 결과를 다시 담는다.
words = ["Movie.", "Two,"]
words = [w.replace(".", "") for w in words]
words = [w.replace(",", "") for w in words]
print(words)
# ['Movie', 'Two']

lower

메서드

영어 대문자를 소문자로 바꾼 새 글자를 만든다.

s.lower()

  • 원본은 그대로다. 리스트의 모든 단어에 쓰려면 새 리스트로 다시 담는다.
print("Python".lower())
# python

08

리스트

순서가 있고 칸을 고칠 수 있다. append 같은 함수는 리스트를 고치고 None을 돌려준다.

리스트 만들기

문법

대괄호 안에 값을 쉼표로 적는다. 빈 리스트는 [] 또는 list()다.

[10, "Python", 3.14]

  • 한 리스트 안에 정수와 글자가 같이 있어도 된다.
  • 첫 칸 번호는 0이다.
lst = [10, "Python", 3.14]
print(lst)

칸에 넣기

문법

있는 번호에 새 값을 넣으면 그 칸만 바뀐다.

lst[번호] = 값

  • 없는 번호에 넣으면 오류다. 뒤를 늘리려면 append를 쓴다.
  • lst[-1] = "Python"은 마지막 칸이다.
lst = [1, 2, 3, 4, 5]
lst[1] = 200
lst[-1] = "Python"
print(lst)
# [1, 200, 3, 4, 'Python']

append

메서드

값 하나를 맨 뒤에 한 칸으로 붙인다.

lst.append(값)

  • 리스트를 넘겨도 풀지 않는다. [1, 2].append([3, 4])는 [1, 2, [3, 4]]가 된다.
  • 결과값은 None이다. lst = lst.append(1)이라고 쓰면 lst가 None이 된다.
lst = ["Banana", "Cherry"]
lst.append("Apple")
print(lst)
print(lst.append("Mango"))
# ['Banana', 'Cherry', 'Apple']
# None

extend

메서드

리스트 안을 풀어서 칸을 하나씩 뒤에 붙인다.

lst.extend(리스트)

  • [1, 2].extend([3, 4])는 [1, 2, 3, 4]다.
  • 이것도 None을 돌려준다.
lst = [1, 2]
lst.extend([3, 4, 5])
print(lst)
# [1, 2, 3, 4, 5]

+ 와 *

연산자

+는 이어 붙인 새 리스트, *는 반복한 새 리스트다. 원래 리스트는 안 바뀐다.

a + b

  • 리스트끼리는 되고, 리스트와 튜플은 안 된다.
  • (1, 2) * 3은 (1, 2, 1, 2, 1, 2)다.
a = [1, 2, 3]
b = [4, 5]
print(a + b)
print(a)

[[x, y] for x, y in zip(students, grades)]

sum

(10,)

값 하나짜리 튜플에는 쉼표. (10)은 정수.

t = (10,)
n = (10)

눌러서 코드 보기

d[키]

있으면 고치고, 없으면 새로 만든다. 없는 키를 읽으면 오류.

menu["Pizza"] = 8500
menu["Ice Cream"] = 2000
del menu["Tteokbokki"]

눌러서 코드 보기

get / pop

get은 없어도 None. pop은 키를 지우고 값을 돌려준다.

d.get("address")    # None
d.pop("status")

눌러서 코드 보기

in d

키만 본다.

"major" in d    # 키면 True
"Math" in d      # 값이면 False
