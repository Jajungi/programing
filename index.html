01

출력과 입력Output and input

계산이 끝나도 결과는 표준 출력에 스스로 나타나지 않는다. 보여줄 때만 print를 호출한다.A finished calculation does not appear by itself. Call print only when the result should be shown.

print

함수function

특징Behavior

print는 인자(argument)를 표준 출력(standard output)에 기록하는 함수(function)다. 호출 자체는 항상 None을 반환한다. 화면에 나타난 내용과 반환값(return value)은 별개다.

print is a function that writes its arguments to standard output. The call itself always returns None. What appears on the screen is separate from the return value.

사용Usage

print(값들, sep=" ", end="\n")

인자는 쉼표로 나눈다. 구분자(separator)의 기본값은 공백 하나이고, 끝을 닫는 문자의 기본값은 줄바꿈이다. 수와 문자열(string)을 한 호출에 함께 둘 수 있다. +로 문자열과 수를 연결하면 TypeError다.

Separate arguments with commas. The default separator is one space, and the default ending is a newline. A number and a string may share one call. Joining a string and a number with + raises TypeError.

보충Notes

반환값을 변수에 대입하면 출력은 이루어지지만 변수에는 None이 남는다. reverse는 print의 매개변수(parameter)가 아니므로 print(lst, reverse=True)도 TypeError다. 역순 출력은 sorted나 슬라이스(slice)의 일이다.

Assigning the return value stores None, even though the output still appears. reverse is not a parameter of print, so print(lst, reverse=True) also raises TypeError. Reversing belongs to sorted or to a slice.

예시Example

b = 2
print("b =", float(b))
# b = 2.0

x = print(1)
# 1이 출력되고 x는 None

input

함수function

특징Behavior

input은 표준 입력에서 한 줄을 읽어 문자열로 반환하는 함수다. 숫자가 보여도 자료형(type)은 str이다.

input is a function that reads one line from standard input and returns it as a string. Even a numeric-looking line has type str.

사용Usage

input("안내 문구")

안내 문구는 선택이다. Enter 앞의 문자만 반환되고, 줄바꿈 자체는 포함되지 않는다. 정수 연산에 쓰려면 int(input())처럼 형 변환(type conversion)을 먼저 한다.

The prompt is optional. Only the characters before Enter are returned; the newline itself is not included. For integer arithmetic, convert first, as in int(input()).

보충Notes

int는 정수 형태의 문자열만 받는다. abc나 9.0이라는 글을 int에 직접 넣으면 ValueError다.

int accepts only a string that is already an integer form. Passing the text abc or 9.0 straight to int raises ValueError.

예시Example

n = int(input("Enter a number: "))
# 4를 입력하면 n은 정수 4

f-string

표기notation

특징Behavior

f-string은 문자열을 만드는 표기다. 중괄호 안의 식(expression)을 계산해 그 자리에 넣는다. 이 표기만으로는 출력되지 않는다.

An f-string is notation that builds a string. It evaluates the expression inside braces and inserts the result. The notation alone does not print anything.

사용Usage

f"글자 {식} 글자"

따옴표 앞에 f를 붙인다. 중괄호 안에는 이름뿐 아니라 연산과 비교도 둘 수 있다. 화면에 내려면 print에 넘긴다.

Prefix the quotes with f. The braces may hold a name, an operation, or a comparison. Pass the result to print when it should be shown.

예시Example

one, two, three = 1, 2, 3
print(f"one<two<three : {one < two < three}")
# one<two<three : True

#

표기notation

특징Behavior

주석(comment)으로 실행에서 빼는 기호는 #다. 그 위치부터 그 줄의 끝까지 인터프리터가 읽지 않는다.

The comment marker is #. From that point to the end of the line, the interpreter does not read the text.

사용Usage

# 여기부터 줄 끝은 무시

코드와 같은 줄의 뒤에도 둘 수 있다. 설명을 남기거나, 한 줄을 잠시 실행에서 제외할 때 쓴다.

It may also follow code on the same line. Use it to leave a remark, or to keep one line out of execution for the moment.

보충Notes

"""..."""는 주석이 아니라 여러 줄 문자열이다. 이름에 대입하지 않으면 그 값은 버려진다. 실습 파일은 이 문자열로 코드 블록을 꺼 두었다.

"""...""" is a multiline string, not a comment. If it is not assigned to a name, the value is discarded. The lab files use that string to hold a block of code out of the way.

예시Example

print(1)
# print(2)  이 줄은 실행되지 않는다

02

변수와 자료형Names and types

이름은 값을 가리킨다. = 은 같다는 비교가 아니라 대입(assignment)이다.A name refers to a value. = is assignment, not a comparison of equality.

=

연산자operator

특징Behavior

대입 연산자(assignment operator)는 오른쪽 식(expression)을 계산한 뒤, 그 결과를 왼쪽 이름에 연결한다. 비교에는 ==를 쓴다.

The assignment operator evaluates the expression on the right, then binds that result to the name on the left. Equality uses ==.

사용Usage

이름 = 식

왼쪽은 이름이어야 한다. 이미 있는 이름에 다시 대입하면 예전의 연결은 끊기고 새 값을 가리킨다. n = n - 2는 현재 값으로 오른쪽을 계산한 다음 그 결과를 다시 n에 넣는다.

The left side must be a name. Assigning again to an existing name drops the old binding and refers to the new value. n = n - 2 evaluates the right side from the current value, then stores the result back in n.

예시Example

n = 9
n = n - 2
# n은 7

a = b = 값

표기notation

특징Behavior

연쇄 대입은 오른쪽 식을 한 번 계산하고, 그 같은 결과를 왼쪽의 이름들에 차례로 연결한다.

Chained assignment evaluates the right-hand expression once and binds that same result to each name on the left.

사용Usage

a = b = 식

이름들은 같은 값을 가리킨다. 정수를 이렇게 나눠 담는 것은 실습의 a = b = 2와 같다.

The names refer to the same value. Sharing an integer this way is the lab form a = b = 2.

예시Example

a = b = 2
# a와 b 모두 2

언패킹

표기notation

특징Behavior

언패킹(unpacking)은 묶음의 칸을 왼쪽 이름들에 순서대로 나눠 담는다. 리스트(list), 튜플(tuple), 문자열처럼 순서가 있는 값에 쓴다.

Unpacking places each element of a sequence into the names on the left, in order. It applies to an ordered value such as a list, a tuple, or a string.

사용Usage

a, b = 묶음

왼쪽 이름의 개수와 오른쪽 칸의 개수가 같아야 한다. 다르면 ValueError다. 쉼표로 나뉜 오른쪽은 튜플로 묶인 뒤 풀린다.

The number of names on the left must equal the number of elements on the right. A mismatch raises ValueError. A comma-separated right side is packed into a tuple and then unpacked.

예시Example

name, age = ["Ada", "20"]
# name은 "Ada", age는 "20"

int float str bool

자료형type

특징Behavior

자료형(type)은 값이 어떤 연산에 들어갈 수 있는지를 정한다. 이 실습의 기본 형은 정수 int, 실수 float, 문자열 str, 논리값 bool이다. bool의 값은 True와 False뿐이다.

A type decides which operations a value may enter. The basic types in these labs are the integer int, the float, the string str, and the Boolean bool. The only Boolean values are True and False.

사용Usage

type(값)

type(값)은 그 값의 자료형을 반환한다. 출력에 찍으면 <class 'int'>처럼 보인다. 형 이름 자체로 변환할 때는 다음 장의 int, float, str을 호출한다.

type(value) returns the type of that value. Printed, it looks like <class 'int'>. To convert, call int, float, or str, covered in the next chapter.

예시Example

number = 9
print(type(number))
# <class 'int'>

형 변환Type conversion

변환 함수는 새 자료형의 값을 만들어 반환한다. 원래 이름은 다시 대입하기 전까지 그대로다.A conversion function builds and returns a value of the new type. The original name is unchanged until you assign again.

int()

함수function

특징Behavior

int는 정수로 변환한 새 값을 반환하는 함수다. 실수는 소수점 아래를 버리고, 정수 형태의 문자열은 그 정수로 읽는다.

int is a function that returns a new integer. A float loses its fractional part. A string in integer form is read as that integer.

사용Usage

int(값)

int(9.9)는 9다. int("9")도 9다. 소수점이 적힌 글 "9.0"은 int가 직접 받지 않는다. 그때는 int(float("9.0"))처럼 float를 거친다.

int(9.9) is 9. int("9") is also 9. The text "9.0", which contains a decimal point, is not accepted directly. Go through float: int(float("9.0")).

보충Notes

input의 결과는 항상 문자열이므로, 합계나 횟수에 쓰려면 변환이 먼저다. 변환 결과를 이름에 담지 않으면 원래 변수는 바뀌지 않는다.

The result of input is always a string, so convert it before using it as a total or a count. The original variable does not change unless the converted result is assigned to a name.

예시Example

int(9.9)          # 9
int("9")          # 9
int(float("9.0"))  # 9

float()

함수function

특징Behavior

float는 실수로 변환한 새 값을 반환한다. 정수 2는 2.0이 되고, 실수 형태의 문자열도 읽는다.

float returns a new floating-point value. The integer 2 becomes 2.0, and a string in float form is read as well.

사용Usage

float(값)

나눗셈 /의 결과는 피연산자가 정수여도 float다. 화면의 정수가 사실 실수인지 보려면 float로 만들거나 type으로 확인한다.

The result of / is a float even when both operands are integers. To see that a displayed whole number is actually a float, convert with float or inspect it with type.

예시Example

b = 2
print(float(b))
# 2.0

str()

함수function

특징Behavior

str은 값을 문자열로 나타낸 새 값을 반환한다. 수 자체는 문자열이 아니므로, +로 글자와 이어 붙이려면 이 변환이 필요하다.

str returns a new string that represents the value. A number is not a string, so this conversion is required before joining it to text with +.

사용Usage

str(값)

print에 쉼표로 넘길 때는 str이 없어도 된다. print가 각 인자를 따로 출력하기 때문이다. +를 쓰는 문장에서만 형이 맞아야 한다.

str is unnecessary when the value is passed to print with a comma, because print writes each argument on its own. The types must agree only in an expression that uses +.

예시Example

a = 1
print("a = " + str(a))
# a = 1

list()

함수function

특징Behavior

list는 인자로 받은 묶음을 새 리스트(list)로 복사해 반환한다. 인자가 없으면 빈 리스트다. []와 같다.

list returns a new list copied from the sequence it is given. With no argument it returns an empty list, the same object kind as [].

사용Usage

list(묶음)

문자열을 넣으면 문자 하나씩이 칸이 된다. 튜플을 넣으면 그 칸을 담은 가변(mutable) 리스트가 된다. 원본 튜플은 바뀌지 않는다.

A string becomes one element per character. A tuple becomes a mutable list of those elements. The original tuple is unchanged.

예시Example

list()          # []
list("ab")      # ['a', 'b']
list((1, 2))    # [1, 2]

tuple()

함수function

특징Behavior

tuple은 인자로 받은 묶음을 새 튜플로 만들어 반환한다. 인자가 없으면 빈 튜플이고, ()와 같다.

tuple returns a new tuple built from the sequence it is given. With no argument the result is the empty tuple, the same as ().

사용Usage

tuple(묶음)

리스트를 더 이상 수정하지 않을 묶음으로 고정할 때 쓴다. 만들어진 튜플의 칸은 대입으로 바꿀 수 없다.

Use it to freeze a list into a sequence that will not be modified. Elements of the resulting tuple cannot be replaced by assignment.

예시Example

tuple([1, 2, 3])
# (1, 2, 3)

dict()

함수function

특징Behavior

dict는 빈 딕셔너리(dictionary)를 반환한다. {}도 빈 딕셔너리이며, 빈 집합이 아니다.

dict returns an empty dictionary. {} is also an empty dictionary, not an empty set.

사용Usage

dict()

칸을 미리 정해 만들 때는 중괄호 안에 키: 값을 적는다. dict()로 시작한 뒤 키를 하나씩 대입해도 된다.

To create it with entries already in place, write key: value pairs inside braces. Starting from dict() and then assigning keys one by one is also valid.

empty = dict()

04

연산자Operators

연산자(operator)는 피연산자를 받아 새 값을 만든다. 복합 대입만 왼쪽 이름을 다시 연결한다.An operator takes operands and produces a new value. Only an augmented assignment rebinds the name on the left.

산술

연산자operator

특징Behavior

산술 연산자는 계산 결과를 새로 반환한다. 피연산자가 실수이면 결과도 실수다. /는 양쪽이 정수여도 항상 float를 반환한다. //는 몫, %는 나머지, **는 거듭제곱이다.

An arithmetic operator returns a new result. If an operand is a float, the result is a float. / always returns a float, even for two integers. // is the floor quotient, % is the remainder, and ** is exponentiation.

사용Usage

a + b a / b a // b a % b a ** b

실습의 9.0으로 보면 9.0 / 2는 4.5, 9.0 % 2는 1.0, 9.0 * 2는 18.0, 9.0 // 2는 4.0, 9.0 ** 3은 729.0이다. **의 지수가 0.5이면 제곱근이다.

With the lab value 9.0: 9.0 / 2 is 4.5, 9.0 % 2 is 1.0, 9.0 * 2 is 18.0, 9.0 // 2 is 4.0, and 9.0 ** 3 is 729.0. An exponent of 0.5 is a square root.

보충Notes

문자열과 리스트와 튜플에서 +는 이어 붙인 새 값을, *는 정수 횟수만큼 반복한 새 값을 만든다. 이 경우에도 원본은 유지된다.

For a string, a list, or a tuple, + builds a new joined value and * builds a new value repeated an integer number of times. The originals stay as they were.

예시Example

init_number = 9.0
init_number / 2     # 4.5
init_number // 2    # 4.0
init_number % 2     # 1.0
init_number ** 3    # 729.0

+= -= *=

연산자operator

특징Behavior

복합 대입(augmented assignment)은 이름에 들어 있는 값과 오른쪽을 계산한 뒤, 그 결과를 같은 이름에 다시 대입한다.

Augmented assignment computes with the value currently bound to the name and the right-hand side, then assigns the result back to that name.

사용Usage

이름 += 값

n *= 2는 n = n * 2와 같다. 더하기와 빼기도 같은 꼴이다. 왼쪽은 이미 값이 있는 이름이어야 한다.

n *= 2 is the same computation as n = n * 2. Addition and subtraction follow the same pattern. The left side must already be a name that holds a value.

예시Example

n = 4
n *= 2
# n은 8

비교

연산자operator

특징Behavior

비교 연산자는 bool을 반환한다. ==는 값이 같은지, !=는 다른지 묻는다. =와 혼동하지 않는다.

A comparison operator returns a bool. == asks whether the values are equal, and != asks whether they differ. Do not confuse either with =.

사용Usage

a == b a < b < c

연쇄 비교 1 < 2 < 3은 이웃한 비교가 모두 참일 때 True다. 한쪽이라도 거짓이면 False다.

The chained comparison 1 < 2 < 3 is True only when every neighboring comparison is true. One false neighbor makes the whole expression False.

예시Example

print(2 == 3)      # False
print(1 < 2 < 3)    # True

in

연산자operator

특징Behavior

in은 포함 여부를 bool로 반환하는 연산자다. 어디를 보는지는 오른쪽 자료형에 따라 달라진다.

in is an operator that returns a bool for membership. What it inspects depends on the type on the right.

사용Usage

값 in 묶음

문자열에서는 연속된 부분 문자열을 본다. 리스트와 튜플에서는 칸의 값이 같은지를 본다. 딕셔너리에서는 키(key)만 본다. 값이 들어 있어도 키가 아니면 False다.

In a string it looks for a contiguous substring. In a list or a tuple it looks for an equal element. In a dictionary it looks only at keys. A matching value that is not a key is False.

보충Notes

not in은 그 결과의 부정이다. 실습의 "LOL" not in t처럼 없음을 물을 때 쓴다.

not in is the negation of that result. The labs use it to ask about absence, as in "LOL" not in t.

예시Example

"Py" in "Python"                 # True
"Math" in {"major": "Math"}      # False, 값은 보지 않는다

반복Loops

반복문(loop)은 조건이나 묶음의 칸이 남아 있는 동안 본문을 다시 실행한다.A loop runs its body again while a condition holds, or while elements of a sequence remain.

while

문statement

특징Behavior

while은 조건식(condition)이 참인 동안 들여쓴 본문을 반복하는 문이다. 조건을 거짓으로 만드는 일이 본문 안에 있어야 반복이 끝난다.

while is a statement that repeats its indented body while the condition is true. Something inside the body must eventually make that condition false.

사용Usage

while 조건:

조건 뒤에는 콜론을 두고, 본문은 들여쓴다. 길이가 2 미만인 문자열을 다시 받는 실습처럼, 아직 성립하지 않은 입력을 거를 때 쓴다.

Place a colon after the condition and indent the body. Use it to reject input that is not yet valid, as in the lab that reads again while a string is shorter than 2.

예시Example

while len(s) < 2:
    s = input()

for

문statement

특징Behavior

for는 묶음의 칸을 앞에서부터 이름에 하나씩 연결하며 본문을 실행한다. 묶음 자체를 보통 변경하지 않고, 각 칸을 읽어 새 결과를 만든다.

for binds each element of a sequence to the name, from front to back, and runs the body. It usually does not modify the sequence; it reads each element and builds a new result.

사용Usage

for 이름 in 묶음:

문자열이면 문자가, 리스트면 칸의 값이 이름에 들어간다. 횟수가 정해진 반복은 range와 함께 쓴다.

Over a string, the name receives each character. Over a list, it receives each element. A counted repetition is written together with range.

예시Example

for ch in "Hi":
    print(ch)
# H
# i

range

함수function

특징Behavior

range는 정수 수열을 만들어 for에 넘기는 함수다. 끝 값은 수열에 포함되지 않는다.

range is a function that produces an integer sequence for for. The stop value is not included.

사용Usage

range(시작, 끝, 간격)

range(1, 4)는 1, 2, 3이다. 시작을 생략하면 0부터다. 1부터 n까지 포함하려면 끝을 n + 1로 둔다. 간격이 음수면 감소한다.

range(1, 4) is 1, 2, 3. Omitting the start begins at 0. To include every integer from 1 through n, set the stop to n + 1. A negative step counts downward.

예시Example

for i in range(1, 4):
    print(i)
# 1
# 2
# 3

중첩 for

문statement

특징Behavior

중첩 반복은 바깥 반복이 한 번 진행할 때마다 안쪽 반복이 자기 묶음을 처음부터 다시 돈다.

In a nested loop, each step of the outer loop runs the inner loop over its whole sequence again.

사용Usage

for a in 묶음: for b in 묶음:

구구단처럼 두 개의 독립된 번호가 필요할 때 쓴다. 안쪽 for는 바깥 본문보다 한 단계 더 들여쓴다.

Use it when two independent indexes are required, as in a multiplication table. The inner for is indented one level deeper than the outer body.

예시Example

for i in range(2, 4):
    for j in range(1, 3):
        print(i, j)
# 2 1
# 2 2
# 3 1
# 3 2

인덱스와 슬라이스Index and slice

문자열, 리스트, 튜플은 0부터 번호를 센다. 슬라이스의 끝 번호는 빠진다.Strings, lists, and tuples count from 0. The stop of a slice is excluded.

인덱스

표기notation

특징Behavior

인덱스(index)는 칸의 번호다. 첫 칸은 0이고, 마지막 칸은 -1이다. 그 번호의 칸 하나를 꺼낸다.

An index is the position of an element. The first position is 0, and the last is -1. The notation retrieves that one element.

사용Usage

묶음[번호]

길이가 n이면 유효한 번호는 0부터 n-1까지, 또는 -1부터 -n까지다. 그 밖은 IndexError다. 가운데 칸은 len(묶음) // 2로 구한다.

If the length is n, valid indexes run from 0 through n-1, or from -1 through -n. Anything outside that raises IndexError. The middle element is at len(sequence) // 2.

보충Notes

문자열과 튜플은 이 자리에 대입할 수 없다. 리스트만 lst[i] = 값이 성립한다.

A string or a tuple cannot be assigned at this position. Only a list accepts lst[i] = value.

예시Example

s = "Python"
s[0]     # P
s[-1]    # n

슬라이스

표기notation

특징Behavior

슬라이스(slice)는 구간의 칸으로 새 문자열, 새 리스트, 또는 새 튜플을 만든다. 끝 번호의 칸은 포함하지 않는다. 원본은 유지된다.

A slice builds a new string, list, or tuple from a span of elements. The element at the stop index is not included. The original is left as it was.

사용Usage

묶음[시작:끝:간격]

시작을 비우면 처음부터, 끝을 비우면 마지막까지다. 간격만 음수로 두면 순서가 뒤집힌다. [::-1]이 그 형태다.

An empty start means the beginning, and an empty stop means through the end. A negative step reverses the order. [::-1] is that form.

예시Example

"Python"[1:-1]    # ytho
"Python"[::-1]    # nohtyP

len

함수function

특징Behavior

len은 칸의 개수를 정수로 반환하는 함수다. 마지막 인덱스는 그 값보다 1 작다.

len is a function that returns the number of elements as an integer. The last index is one less than that number.

사용Usage

len(묶음)

문자열은 문자의 수, 리스트와 튜플은 칸의 수, 딕셔너리는 키의 수다. 비어 있으면 0이다.

For a string it is the number of characters, for a list or tuple the number of elements, and for a dictionary the number of keys. An empty value has length 0.

예시Example

len("Python")    # 6

문자열Strings

문자열(string)은 순서가 있는 불변 값이다. 메서드는 원본을 두지 않고 새 문자열이나 리스트를 반환한다.A string is an ordered immutable value. Its methods leave the original in place and return a new string or a new list.

문자열

자료형type

특징Behavior

문자열의 한 칸은 대입으로 바꿀 수 없다. 바꾸려면 슬라이스와 +로 새 문자열을 만들고, 그 결과를 이름에 다시 대입한다.

One character of a string cannot be replaced by assignment. To change the text, build a new string with slices and +, then assign that result back to the name.

사용Usage

s[0] = "a" # 성립하지 않음

첫 문자와 마지막 문자를 바꾸는 실습은 s[-1] + s[1:-1] + s[0]이다. 가운데는 끝 문자를 뺀 구간이다.

The lab that swaps the first and last characters is s[-1] + s[1:-1] + s[0]. The middle is the slice that excludes both ends.

예시Example

s = "Python"
s = s[-1] + s[1:-1] + s[0]
# nythoP

split

메서드method

특징Behavior

split은 문자열을 잘라 리스트로 반환하는 메서드(method)다. 원래 문자열은 바뀌지 않는다.

split is a method that divides a string and returns a list. The original string does not change.

사용Usage

s.split(구분자)

인자를 비우면 연속된 공백을 구분자(separator)로 보고, 빈 칸은 결과에 넣지 않는다. 구분자를 주면 그 문자열을 경계로 자른다.

With no argument, consecutive whitespace is the separator and empty pieces are omitted. With a separator, the string is divided on that text.

예시Example

"a b".split()       # ['a', 'b']
"a,b".split(",")    # ['a', 'b']

join

메서드method

특징Behavior

join은 묶음의 각 조각을 구분자로 이어 새 문자열을 반환한다. 구분자가 메서드 앞에 오고, 이어 붙일 재료가 인자다.

join returns a new string made by placing the separator between the pieces. The separator stands before the method, and the pieces are the argument.

사용Usage

구분자.join(묶음)

인자의 칸은 모두 문자열이어야 한다. 수가 섞이면 TypeError다. 문자열을 넘기면 문자 하나씩이 조각이 된다.

Every element of the argument must be a string. A number among them raises TypeError. Passing a string treats each character as a piece.

예시Example

" ".join(["I", "love"])
"-".join("HELLO")    # H-E-L-L-O

replace

메서드method

특징Behavior

replace는 찾은 부분을 바꾼 새 문자열을 반환한다. 호출만으로는 변수에 들어 있는 문자열이 바뀌지 않는다.

replace returns a new string in which the found text has been replaced. The call alone does not change the string stored in the variable.

사용Usage

s.replace(찾을말, 바꿀말)

반영하려면 s = s.replace(...)처럼 다시 대입한다. 빈 문자열로 바꾸면 그 부분이 지워진다.

To keep the result, assign it back, as in s = s.replace(...). Replacing with an empty string deletes that part.

예시Example

s = "a.b.c"
s = s.replace(".", "")
# abc

lower

메서드method

특징Behavior

lower는 영문 대문자를 소문자로 바꾼 새 문자열을 반환한다. 원본은 유지된다.

lower returns a new string in which ASCII uppercase letters have been turned into lowercase. The original is unchanged.

사용Usage

s.lower()

비교 전에 양쪽을 같은 형태로 맞출 때 쓴다. 결과를 이름에 담지 않으면 다음 줄의 s는 이전 그대로다.

Use it to put both sides of a comparison into the same case. Unless the result is assigned to a name, s on the next line is still the old string.

예시Example

"Python".lower()    # python

리스트Lists

리스트(list)는 순서가 있고 칸을 바꿀 수 있는 값이다. 메서드마다 원본을 고치는지, None을 반환하는지가 다르다.A list is an ordered mutable value. Each method differs in whether it changes the original and whether it returns None.

리스트 만들기

자료형type

특징Behavior

대괄호는 리스트를 만드는 표기다. 칸의 순서는 적은 순서로 유지된다. 빈 리스트는 [] 또는 list()다.

Brackets are the notation for a list. Element order is the order written. An empty list is [] or list().

사용Usage

[값, 값] list()

칸에는 수, 문자열, 리스트처럼 서로 다른 자료형이 함께 있을 수 있다. 만든 뒤에는 인덱스와 슬라이스가 문자열과 같은 규칙으로 동작한다.

Elements may mix types, including numbers, strings, and lists. After creation, indexing and slicing follow the same rules as for a string.

예시Example

lst = [10, 20, 30]
empty = []

칸에 대입

표기notation

특징Behavior

리스트는 가변(mutable)이므로 있는 번호의 칸을 다른 값으로 바꿀 수 있다. 이 대입은 새 리스트를 만들지 않고 그 객체를 고친다.

A list is mutable, so an existing index may be replaced with another value. This assignment changes that object; it does not build a new list.

사용Usage

lst[번호] = 값

번호는 이미 있는 칸이어야 한다. 없는 번호에 대입하면 IndexError다. 뒤를 늘리는 일은 append의 일이다.

The index must already exist. Assigning to a missing index raises IndexError. Growing the end is the job of append.

예시Example

lst = [10, 20, 30]
lst[1] = 15
# [10, 15, 30]

append

메서드method

특징Behavior

append는 인자 전체를 마지막 칸 하나로 추가하고 None을 반환한다. 제자리 변경(in-place)이다.

append adds the entire argument as one new last element and returns None. The change is in-place.

사용Usage

lst.append(값)

인자가 리스트여도 한 칸에 그 리스트가 통째로 들어간다. 안을 풀어 넣으려면 extend다.

Even when the argument is a list, that list occupies a single element. To insert its contents, use extend.

보충Notes

lst = lst.append(x)는 추가가 끝난 리스트를 버리고 이름에 None을 넣는다. 호출만 하고 대입하지 않는다.

lst = lst.append(x) discards the updated list and stores None in the name. Call the method and do not assign its result.

예시Example

lst = [1, 2]
lst.append([3])
# [1, 2, [3]]
# append의 반환값은 None

extend

메서드method

특징Behavior

extend는 인자의 칸을 풀어 리스트 뒤에 차례로 추가하고 None을 반환한다. 원본 리스트를 고친다.

extend unpacks the argument and appends each of its elements, then returns None. It modifies the original list.

사용Usage

lst.extend(묶음)

인자는 리스트, 튜플, 문자열처럼 반복할 수 있는 값이다. 문자열을 넘기면 문자가 한 칸씩 들어간다.

The argument is an iterable such as a list, a tuple, or a string. A string contributes one character per element.

예시Example

a = [1, 2]
a.extend([3, 4])
# [1, 2, 3, 4]

+ 와 *

연산자operator

특징Behavior

+와 *는 리스트를 고치지 않고 새 리스트를 반환한다. append, extend와 반환의 성질이 다르다.

+ and * return a new list and do not modify the operands. That is a different contract from append and extend.

사용Usage

a + b a * n

+의 양쪽은 같은 종류의 묶음이어야 한다. *의 횟수는 정수다. 결과를 쓰려면 이름에 대입한다.

Both sides of + must be sequences of the same kind. The count in * is an integer. Assign the result if it should be kept.

예시Example

[1, 2] + [3]     # [1, 2, 3]
[1, 2] * 2       # [1, 2, 1, 2]

insert

메서드method

특징Behavior

insert는 지정한 번호에 값을 끼워 넣고, 뒤 칸을 한 자리씩 민다. 반환값은 None이다.

insert places a value at the given index and shifts the later elements one position to the right. The return value is None.

사용Usage

lst.insert(번호, 값)

0은 맨 앞이다. 길이보다 큰 번호는 마지막에 추가하는 것과 같다.

0 is the front. An index past the length appends at the end.

예시Example

lst = [10, 30]
lst.insert(1, 15)
# [10, 15, 30]

remove

메서드method

특징Behavior

remove는 인자와 같은 값의 첫 칸을 지우고 None을 반환한다. 번호가 아니라 값으로 찾는다.

remove deletes the first element equal to the argument and returns None. It searches by value, not by index.

사용Usage

lst.remove(값)

같은 값이 여러 칸이면 가장 앞의 하나만 지운다. 그 값이 없으면 ValueError다.

If the value occurs more than once, only the first occurrence is removed. A missing value raises ValueError.

예시Example

lst = [10, 20, 20]
lst.remove(20)
# [10, 20]

pop

메서드method

특징Behavior

pop은 지정한 번호의 칸을 리스트에서 빼고, 그 뺀 값을 반환한다. remove와 달리 반환값이 있다.

pop removes the element at the given index and returns that removed value. Unlike remove, it has a return value.

사용Usage

lst.pop(번호)

번호를 생략하면 마지막 칸을 뺀다. 없는 번호는 IndexError다.

Omitting the index removes the last element. A missing index raises IndexError.

예시Example

lst = [10, 20, 30]
print(lst.pop(0))    # 10
# lst는 [20, 30]

del

문statement

특징Behavior

del은 번호의 칸을 지우는 문(statement)이다. 메서드가 아니므로 반환값을 변수에 받을 수 없다.

del is a statement that deletes the element at an index. It is not a method, so there is no return value to bind.

사용Usage

del lst[번호]

지운 값이 필요하면 pop을 쓴다. 값으로 찾고 반환이 필요 없으면 remove를 쓴다.

Use pop when the removed value is needed. Use remove when the search is by value and the return value is not needed.

예시Example

lst = [10, 20, 30]
del lst[0]
# [20, 30]

count

메서드method

특징Behavior

count는 인자와 같은 칸이 몇 개인지 정수로 반환한다. 리스트는 바뀌지 않는다.

count returns, as an integer, how many elements equal the argument. The list is unchanged.

사용Usage

lst.count(값)

없으면 0이다. 오류가 아니다. index와 이 점이 다르다.

A missing value yields 0, not an error. That is the difference from index.

예시Example

[10, 20, 20].count(20)    # 2
[10].count(99)             # 0

index

메서드method

특징Behavior

index 메서드는 인자와 같은 첫 칸의 번호를 반환한다. 칸을 꺼내는 표기 lst[i]와 방향이 반대다.

The index method returns the position of the first element equal to the argument. It runs in the opposite direction from the notation lst[i].

사용Usage

lst.index(값)

없으면 ValueError다. count처럼 0을 반환하지 않는다.

A missing value raises ValueError. It does not return 0 the way count does.

예시Example

[10, 20, 30].index(20)    # 1

sorted

함수function

특징Behavior

sorted는 정렬된 새 리스트를 반환하는 함수다. 인자로 넘긴 리스트의 순서는 그대로다.

sorted is a function that returns a new list in sorted order. The list passed in keeps its original order.

사용Usage

sorted(묶음)

기본은 오름차순이다. 역순의 새 리스트가 필요하면 sorted(lst, reverse=True)다. 이 reverse는 sorted의 매개변수다.

The default order is ascending. For a new list in reverse order, write sorted(lst, reverse=True). Here reverse is a parameter of sorted.

예시Example

lst = [3, 1, 2]
print(sorted(lst))    # [1, 2, 3]
# lst는 여전히 [3, 1, 2]

sort

메서드method

특징Behavior

sort는 그 리스트의 순서를 제자리에서 정렬하고 None을 반환한다. sorted와 달리 새 리스트를 만들지 않는다.

sort orders that list in place and returns None. Unlike sorted, it does not build a new list.

사용Usage

lst.sort()

호출 뒤에 리스트 자체를 보면 정렬되어 있다. print(lst.sort())가 찍는 것은 None이다.

After the call, the list itself is sorted. What print(lst.sort()) prints is None.
