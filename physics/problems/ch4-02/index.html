Electric field from a polynomial potential

다항 전위에서 전기장

The electrostatic potential in a region is V(x,y,z)=x2y+3xyz+zy2V(x,y,z) = x^2 y + 3xyz + z y^2V(x,y,z)=x2y+3xyz+zy2 (SI units). Find the electric field vector E⃗=−∇V\vec E = -\nabla VE=−∇V as a function of coordinates.
한글
V=x2y+3xyz+zy2V=x^2y+3xyz+zy^2V=x2y+3xyz+zy2. E⃗=−∇V\vec E=-\nabla VE=−∇V.

  2. 0 derivative. ∂V/∂x=2xy+3yz\partial V/\partial x = 2xy + 3yz∂V/∂x=2xy+3yz, so Ex=−(2xy+3yz)E_x = -(2xy + 3yz)Ex​=−(2xy+3yz).
  3. 0 derivative. ∂V/∂y=x2+3xz+2zy\partial V/\partial y = x^2 + 3xz + 2zy∂V/∂y=x2+3xz+2zy, so Ey=−(x2+3xz+2yz)E_y = -(x^2 + 3xz + 2yz)Ey​=−(x2+3xz+2yz).
  4. 0 derivative. ∂V/∂z=3xy+y2\partial V/\partial z = 3xy + y^2∂V/∂z=3xy+y2, so Ez=−(3xy+y2)E_z = -(3xy + y^2)Ez​=−(3xy+y2).
  5. Vector form. E⃗=−(2xy+3yz) x^+(x2+3xz+2yz) y^+(3xy+y2) z^\vec E = -(2xy+3yz)\,\hat x + (x^2+3xz+2yz)\,\hat y + (3xy+y^2)\,\hat zE=−(2xy+3yz)x^+(x2+3xz+2yz)y^​+(3xy+y2)z^ with overall minus signs grouped as above.
